# Personal cat food allergy checker

I created this personal project, because I found out that my cat has allergies of most ingredients found in dry food. 
I was in pursuit to find her new food that wasn't harmful to her. The problem was, I had to look at each bag of dry food at the store,
look at each ingredient in small text, and compare it to the list of allergies of hers. That process was time consuming and frankly, 
discouraging. So I decided to create small code, that would automate that problem for me.

---

##  Features

- Responsive design
- Clean, modern, and easy-to-read layout  
- Sections for profile, education, skills, and work experience  
- Simple customization — just edit the HTML and CSS files  
- Lightweight and fast (no frameworks or JavaScript required)

---

## Technologies Used

- **HTML5** – for structure and content  
- **CSS3** – for styling and layout
